# PD-138 Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the one-screen landing with the full story from `design/Landing.dc.html` (hero with a 3D holo card, how it works, a 3D pack-opening showcase, a chase-card marquee, sets, a deck-builder preview, safe trading, FAQ, a final call to action), a footer on every public page, and a price sort in the catalog, with every claim true to the project.

**Architecture:** `app/(public)/page.tsx` stays a Server Component that reads its data once (`landingData`) and composes `components/landing/*`; only the parts with behaviour are client islands. The two three.js modules become TypeScript under `components/landing/three/`, import `three` from npm on demand, and run only on a desktop with a fine pointer — everyone else, and the server render, gets the poster. The API's card search gains `price_desc`/`price_asc` with an index.

**Tech Stack:** NestJS + Prisma 7 (API), Zod 4 (shared), Next 16.3.5, React 19.2, Tailwind 4, three.js 0.186.0.

**Spec:** `docs/superpowers/specs/2026-10-12-pd-138-landing-design.md`

```ts
'use client';
import { useEffect, useState } from 'react';

export type ThreeMode = 'poster' | 'full';

function webgl(): boolean {
  try {
    const canvas = document.createElement('canvas');
    return !!(canvas.getContext('webgl2') ?? canvas.getContext('webgl'));
  } catch {
    return false;
  }
}

// Decided after mount: the server cannot know, and a mode chosen during render
// would hydrate differently from the server's poster.
export function useThreeMode(): ThreeMode {
  const [mode, setMode] = useState<ThreeMode>('poster');
  useEffect(() => {
    const nav = navigator as Navigator & {
      connection?: { saveData?: boolean };
      deviceMemory?: number;
    };
    const capable =
      matchMedia('(pointer: fine)').matches &&
      !matchMedia('(prefers-reduced-motion: reduce)').matches &&
      nav.connection?.saveData !== true &&
      (nav.hardwareConcurrency ?? 8) > 4 &&
      (nav.deviceMemory ?? 8) > 4 &&
      webgl();
    if (capable) setMode('full');
  }, []);
  return mode;
}
```

If the React compiler lint flags `setState` in an effect, keep the pattern and silence nothing: move the check into a `useSyncExternalStore` with `getServerSnapshot = () => 'poster'` instead.

- [ ] **Step 1: `landingData`**

```ts
import 'server-only';
import type { Card, CardSet } from '@pokedrop/shared';
import { searchCards, sets } from '@/lib/api/endpoints/catalog';
import { inventorySummary } from '@/lib/api/endpoints/inventory';
import { serverApi } from '@/lib/api/server';

const CHASE_SIZE = 12;
const CHASE_MIN = 6;

export async function landingData(signedIn: boolean): Promise<LandingData> {
  const [count, setList, chase, summary] = await Promise.allSettled([
    serverApi.call(searchCards({ pageSize: 1 })),
    serverApi.call(sets()),
    serverApi.call(searchCards({ sort: 'price_desc', pageSize: CHASE_SIZE })),
    signedIn ? serverApi.call(inventorySummary()) : Promise.reject(new Error('signed out')),
  ]);
  const priced =
    chase.status === 'fulfilled' ? chase.value.items.filter((c) => c.latestPriceUsd !== null) : [];
  return {
    cardCount: count.status === 'fulfilled' ? count.value.total : null,
    sets: setList.status === 'fulfilled' ? setList.value : [],
    chase: priced.length >= CHASE_MIN ? priced : [],
    completion:
      summary.status === 'fulfilled'
        ? new Map(summary.value.setCompletion.map((s) => [s.setId, { owned: s.owned, total: s.total }]))
        : null,
  };
}
```
